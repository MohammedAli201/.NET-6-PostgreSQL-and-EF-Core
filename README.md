# Teams API with PostgreSQL and Entity Framework Core

A C# learning API for teams, drivers and media records. The project demonstrates ASP.NET Core controllers, a repository/unit-of-work structure, EF Core relationships and PostgreSQL migrations.

## Code guide

| Path | Purpose |
| --- | --- |
| `Controllers/TeamsController.cs` | List, retrieve and create teams |
| `Models/` | Team, driver and media entities |
| `Data/ApiDbContext.cs` | Entity configuration and database context |
| `Repository/` and `Services/` | Repository contracts and unit of work |
| `Migrations/` | PostgreSQL schema history |

## Local setup

The original project targets .NET 6 and EF Core 7. Use compatible development tooling and a local PostgreSQL database. Set `ConnectionStrings__SampleDbConnection` through your shell or development secret store; do not commit a database password.

```bash
dotnet restore
dotnet build
# With a compatible dotnet-ef tool installed:
dotnet ef database update
dotnet run
```

Use the URL printed by the server. `/swagger` is enabled in Development. `POST /Teams` currently receives `name` and `year` as request parameters; inspect the controller rather than assuming a JSON contract.

## Status

Historical learning project. Some generic repository operations deliberately remain unimplemented. There is no application test project in this repository and no claim of production readiness. Database IDs are generated by the PostgreSQL identity column defined in the migration.
